NexuVig

Monitorização de computadores: CPU, memória, disco e estado da ligação, num só painel.

Descarregar para Windows

Windows 10 ou 11 (64 bits) · gratuito · todas as versões

O que faz

  • Mostra-te os dados do teu computador: processador, memória, disco, rede e tempo ligado.
  • Envia esses dados, a cada 30 segundos, para o painel do administrador.
  • Arranca sozinho com o Windows, como serviço.

Como instalar

  1. Descarrega e abre o NexuVig-Setup.exe.
  2. Se o Windows mostrar "O Windows protegeu o seu PC", escolhe Mais informações e depois Executar mesmo assim.
  3. Segue o assistente sem alterar nada (precisa de permissões de administrador).
  4. Abre o NexuVig no menu Iniciar.

Aprovação

Depois de instalado, o computador regista-se sozinho e fica à espera de aprovação. Só passa a contar no painel quando o administrador o aceitar.

Enquanto esperas, o programa já mostra os dados do teu computador.

Que dados são enviados

Nome do computador, sistema operativo, processador, endereços IP, utilização de CPU e memória, espaço em disco e tempo ligado.

Não são enviados ficheiros, programas abertos nem histórico de navegação.

O aviso do Windows aparece porque o instalador não tem assinatura digital paga. O código é público: github.com/serhiivilchak224/NexuVig.

Para desinstalar: Definições > Aplicações > NexuVig.
